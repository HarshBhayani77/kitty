ENGINEERING HIGHLIGHTS

Built for Precision & Resource Efficiency

Structured modular architecture designed to integrate seamlessly on Windows, Linux, and macOS desktops.

01

Pure Procedural Vector Engine

Every polygon, ear tuft, whisker, and fur silhouette is evaluated mathematically via Bézier curves and QPainter paths. Zero bitmap degradation across high-density 4K displays.

QPainterPath Trigonometric Curves Anti-aliased
02

Non-Blocking Telemetry Pipelines

System load monitors operate on isolated background QThreads. CPU, RAM, and GPU queries poll asynchronously without ever dropping animation frame rates or interrupting user focus.

psutil GPUtil Worker QThread
03

Mathematical Sound Synthesis

Purr rumbles (~28 Hz with harmonic overtones) and meow sweeps (450 Hz to 800 Hz) are synthesized directly into 16-bit audio buffers. Eliminates audio asset dependencies and packaging overhead.

Sine Modulation Web Audio API Pygame Mixer
04

Thread-Safe SQLite Persistence

User preferences, custom RGB fur configurations, sticky note positions, and conversation histories are committed safely through a centralized SQLite database manager.

SQLite3 WAL Mode Connection Pool

GETTING STARTED

Run Native Desktop Application

Compatible with Windows 10/11, macOS, and Linux. Requires Python 3.10+.

PowerShell / Bash Terminal
# 1. Clone repository
git clone https://github.com/HarshBhayani77/kitty.git
cd kitty

# 2. Launch on Windows (Auto virtual-env & dependency setup)
.\run.bat

# Or on Linux / macOS:
chmod +x run.sh
./run.sh

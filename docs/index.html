DESKTOP APP CAPABILITIES

Built for Performance, Utility & Joy

Kitty AI isn't just an adorable avatar — it is a fully integrated desktop productivity assistant.

🎨

Pure Procedural Vector Graphics

Rendered natively using PyQt6's QPainter with mathematical Bézier curves and antialiasing. Zero pixelation, ultra-crisp at any monitor DPI or 4K resolution, and zero motion jitter.

  • ✓ Smooth cursor eye-tracking with slit pupils
  • ✓ 80ms natural blink cycle
  • ✓ Dangle carrying physics when dragged
  • ✓ 5 distinct feline coats + custom RGB fur
⚡

1st Click: Real-Time Hardware HUD

Single-click Kitty on your desktop to instantly inspect your computer's health without opening heavy task managers.

  • ✓ Real-time CPU % & core loads via psutil
  • ✓ RAM used/available telemetry
  • ✓ Dedicated GPU monitor via GPUtil
  • ✓ Battery charging percentage & storage metrics
🧠

2nd Click: Multi-Engine AI Companion

Double-click Kitty to open conversational AI with full memory and personality, powered by the top LLM providers.

  • ✓ Google Gemini (gemini-2.5-flash, 1.5-flash)

  • ✓ Local offline models via Ollama (zero API costs)
  • ✓ Persistent chat history in SQLite database

ARCHITECTURE & STACK

Clean, Modular Python Design

Engineered for low resource consumption (<1% CPU idle) and zero desktop interference.

Core Engine

Desktop Runtime

  • UI Framework: PyQt6 (Frameless, Translucent, Always-on-Top)
  • Rendering: Custom procedural QPainter vectors
  • Hardware Monitor: psutil & GPUtil background worker
  • Audio: Synthesized frequency sine sweep (Web Audio / Pygame mixer)
  • Storage: SQLite with thread-safe connection pooling
Companion Website

Web Demo & Portfolio

  • Engine: HTML5 2D Canvas rendering matching Python math 1:1
  • Audio Engine: Web Audio API synthesized purrs & meows
  • Hardware API: Navigator Battery API + Web Workers
  • Zero Dependencies: 100% vanilla client-side code
  • Hosting: 1-click GitHub Pages, Vercel, or Netlify
